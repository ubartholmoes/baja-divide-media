# baja-divide-media

Public media hosting for Ulrich Bartholmoes' Baja Divide FKT Instagram posts (30.12.2026 – 10.01.2027).

- `YYYY-MM-DD_dayN/`, `YYYY-MM-DD_story_*/` – media as published on Instagram (raw URLs are passed to the Instagram API)
- `kit/` – scripts used to produce the posts (audiogram video, 4:5 photos, 9:16 stories, route context, Instagram payloads)
- `stories/state.json` – story counter (every 5th story is a live-tracking story)
